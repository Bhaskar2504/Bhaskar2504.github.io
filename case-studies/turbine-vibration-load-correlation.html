Rotor Dynamics · Steam Turbine

The vibration that followed load.

The alarm value still looked acceptable. The machine’s sensitivity to operating changes did not.

Load correlationRotor responseMechanical verification
ProblemVibration stays below the alarm, but sensitivity changesThe absolute value alone does not explain the risk.
DataLoad / steam transitions + vibration responseCompare repeated operating disturbances over time.
PhysicsThe rotor is becoming more excitableA developing rotor-dynamic issue is plausible, not yet proven.
VerificationPhase · spectrum · alignment · thermal stateUse independent mechanical evidence before concluding.
StatusDiagnostic hypothesisPublic-safe illustrative case; no production outcome is claimed.

Structure: symptom → available evidence → physical interpretation → verification → decision status.

Signal relationship

Same operating disturbance. Larger vibration response.

The useful pattern is the changing gain between operating condition and rotor response.

Developing rotor-dynamic issue

Mechanical unbalance is one plausible explanation, but the pattern is not uniquely diagnostic.

1Compare amplitude + phase, not amplitude alone.
2Review spectrum / harmonic content.
3Check alignment and thermal-state dependence.
4Inspect bearing / rotor condition before concluding.

Key ideaThe useful signal is not only vibration level. It is the changing relationship between vibration and operating condition.
