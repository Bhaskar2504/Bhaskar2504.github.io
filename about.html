About

How I Think

Start with the engineering question, not the algorithm.

I prefer to define the asset, the physical problem, the expected behaviour and the decision that needs to improve before deciding what analytics or AI should be used. That helps keep models connected to operating reality and makes the output easier for engineers to validate.

1. Define the problem

What equipment or process decision needs to become earlier, clearer or more reliable?

2. Understand the physics

Which variables drive the behaviour, and what relationships should hold during normal operation?

3. Build the evidence

Validate measurements, derive useful engineering parameters and examine multivariable behaviour.

4. Make it actionable

Translate the output into an explanation, investigation, maintenance decision or operating action that a user can trust.
